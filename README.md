# 🎮 Hangman Game in Python

This is a simple **command-line Hangman game** built in Python. The player tries to guess a hidden word, one letter at a time, within a limited number of incorrect guesses.

It's a great beginner project to understand Python basics such as strings, loops, conditionals, and user input.

---

## 🛠️ Technologies Used

- Python 3

---

## 📌 Features

- Word guessing with limited attempts
- Tracks incorrect guesses and shows remaining lives
- Visual hangman display using text
- Random word selection from a list
- Easy to customize and expand

---

## 🧠 How It Works
- A word is randomly selected from a list.
- The player has to guess the word letter by letter.
- For every incorrect guess, one life is lost.
- The game ends when:
- All letters are guessed (win)
- All lives are lost (game over)
